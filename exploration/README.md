# Workstream exploration report template

- Question the workstream must answer.
- At least two candidate approaches/tools.
- Same input pages/questions and controlled experiment setup.
- Commands, environment/model versions, hardware, output logs.
- Measured results and failure examples with page numbers.
- Recommendation, risks, limitations, and dependencies on other workstreams.

Required examples from the assignment: compare two layout parsers on the same 20 pages; include Unlimited-OCR single-page and multi-page in the OCR benchmark when available; compare lexical/dense/hybrid and page-image retrieval; verify graph triples; compare ablations A–F. Keep source PDFs and extracted text private.
