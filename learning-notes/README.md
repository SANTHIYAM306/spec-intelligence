# Individual learning notes template

For each required curriculum lesson, record:
1. Concept in your own words (5–10 lines).
2. One concrete example from USB-PD / Type-C / USB4 / Tech 2.
3. Command and output from running the lesson's Build It code.
4. One change you made to test your understanding.
5. A from-scratch exercise and its output.

Do not claim you ran a lesson unless you personally ran it and kept the output. Suggested core topics: PDF layout/OCR, BM25, dense embeddings, hybrid retrieval/RRF, graph triples and provenance, bounded agent loops, citation checks, Recall@k/MRR and ablations.
