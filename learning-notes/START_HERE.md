# Individual learning notes — complete in your own words

The assignment requires a named note file per member. Copy this template to `learning-notes/<your-name>.md` and fill it using actual lessons you ran.

For every required lesson, include:
1. Concept explained in your own words (5–10 lines).
2. One concrete example from an authorised source document.
3. The exact command you ran and a short real output excerpt.
4. One experiment/change you made to test your understanding.
5. A from-scratch exercise (BM25, cosine top-k, MaxSim, chunking, graph traversal or a tiny tool loop).
6. What failed, how you diagnosed it and what you learned.

Do not invent command output, page evidence, experiment results or personal contributions.
